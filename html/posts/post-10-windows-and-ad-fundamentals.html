Day 8 at ReDI: Understanding Windows and Active Directory

By Oriana • May 10 2026 • 3 min read • #security #windows #ReDI

In this session, I learned that Windows security is much more than just using a familiar operating system. Behind the desktop we use every day, there is a whole structure of users, permissions, system folders, security settings, and network management that shapes how safe a computer really is.

Windows Is Not Just One Thing

One of the first things that became clearer to me is that Windows comes in different forms depending on the job it needs to do. There is the version most people use at home, there is Windows Server for business infrastructure, and there are lighter versions for devices like kiosks and embedded systems.

That helped me see Windows less as a single product and more as a family of systems built for different environments.

Why the File System Matters

I also learned that the file system is not just a technical detail. It decides how files are stored, found, and protected. In Windows, NTFS is important because it supports permissions, encryption, compression, journaling, and other features that help with both security and reliability.

Even basic system folders started to make more sense. Program Files holds installed applications, Users contains personal profiles, and the Windows folder holds core operating system files. Understanding that structure makes the system feel less mysterious.

Users, Admins, and Permissions

A big takeaway from this session is the difference between a standard user and an administrator. A standard user can do daily work, but an admin account can change system settings, install software, and manage other accounts.

That difference matters because too much privilege creates risk. The permissions model in Windows exists to control who can read, write, modify, or fully control files and folders. A simple mistake in permissions can expose sensitive data or allow unwanted changes.

The Management Models Finally Clicked

The comparison between standalone systems, workgroups, and domains made this topic much easier to follow. A standalone computer manages itself. A workgroup is still local and separate on each machine. A domain is centralized and much more structured.

That was the moment Active Directory started to make sense to me. It is not just a name you hear in IT. It is the system that helps organizations manage users, devices, authentication, and policies in one place instead of dealing with every machine individually.

Why Active Directory Is So Important

I learned that Active Directory makes life easier for organizations because it centralizes logins, policies, and access control. Instead of creating separate accounts everywhere, everything can be managed from domain controllers.

It also improves consistency. When passwords, permissions, and security rules are handled centrally, it becomes easier to enforce better security across the whole environment.

Security Examples Made It Real

The scenarios in this session were useful because they showed how everyday decisions affect security. A lost laptop with no password, an over-shared payroll folder, or a phishing attack on a domain-joined machine all show different levels of risk.

What stood out to me is that stronger management and better policy control can reduce damage. Group Policy, backups, encryption, and proper permissions all play a role in keeping incidents from becoming disasters.

Windows Security Is Broader Than Antivirus

I liked that we looked at Windows Security as a full set of protections, not just antivirus. Virus and threat protection, account protection, firewall rules, app and browser control, device security, and system health all work together.

It was a good reminder that endpoint security is layered. Real protection comes from combining settings, visibility, safe habits, and the right controls for the business context.

What I’m Taking Away

The main lesson I’m keeping from this session is that Windows administration and security are closely connected. If you understand users, permissions, local versus centralized management, and the role of Active Directory, you already understand a big part of how organizations stay secure.

This session made Windows and AD feel more practical and less intimidating. Instead of seeing them as purely administrative topics, I now see them as part of the everyday foundation of cybersecurity.
